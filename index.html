Provirium

2024.11 –

AR環境アセスメントアプリ

建設予定の風力発電機をスマートフォンのARで現地に配置し、完成後の景観を確かめられるアプリ。GPSと端末の方位から設置地点をAR空間上に置き、距離と方位角は国土地理院の測量計算に沿ってGRS80楕円体上で求めている。手前の建物や人による遮蔽にも対応。

分野
ARアプリ（iOS）
技術
Unity 2022 / C# / AR Foundation / Niantic Lightship ARDK / Google Sheets API
実績
（仮称）西山風力発電開発事業の12基を登録・公開
規模
C# 約3,100行
サイト
flosrum.com/provirium
